# FF14 物价百科 v1.0.4

面向《最终幻想 XIV》国服玩家的桌面查价工具。

当前核心查询链路：
`中文搜索 -> 内置双语映射表 -> ItemID / 英文名 -> Universalis 国服价格`

## 主要功能

- 国服市场板价格查询
- 物品详情、配方、用途、获取方式查看
- 国服 Wiki 词条直达
- 中文 / 英文双语物品映射
- `全部 / HQ / 非 HQ` 价格查看
- 主题颜色调节
- 桌面端窗口透明度调节

## 最新更新

- 对前端源码做了一轮自检和清理，移除重复的搜索结果渲染与启动逻辑
- 收敛当前生效的市场总览、价格表与 Wiki 兜底逻辑，减少旧代码覆盖新逻辑的风险

- 桌面端透明度从固定档位改成 `10%` 到 `100%` 自由滑杆调节

## 启动方式

源码运行：

```bat
start_app.bat
```

发布打包：

```bat
publish_app.bat
```

## 项目结构

```text
ff14/
  desktop/FF14MarketDesktop/   # WinForms + WebView2 桌面壳
  data/                        # 内置数据
  tools/ItemMappingBuilder/    # 双语映射表生成工具
  index.html                   # 前端入口
  app.js                       # 前端逻辑
  styles.css                   # 前端样式
```
