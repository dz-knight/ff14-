# FF14 物价百科 v1.0.9

面向《最终幻想 XIV》国服玩家的桌面查价工具。

当前核心查询链路：
`中文搜索 -> 内置双语映射表 -> ItemID / 英文名 -> Universalis 国服价格`

## 主要功能

- 国服市场板价格查询
- 物品详情、配方、用途、获取方式查看
- 国服 Wiki 词条直达
- 中文 / 英文双语物品映射
- `全部 / HQ / 非 HQ` 价格查看
- 按国服大区筛选市场价格
- 当前区服销售排行
- 配方成本与利润计算
- NPC 商店售价与精确坐标展示
- 主题颜色调节
- 桌面端窗口透明度调节

## 启动方式

源码运行：

```bat
start_app.bat
```

发布打包：

```bat
publish_app.bat
```

已打包版本可从 [GitHub Releases](https://github.com/dz-knight/ff14-/releases) 下载。

## 项目结构

```text
ff14/
  desktop/FF14MarketDesktop/   # WinForms + WebView2 桌面壳
  data/                        # 内置数据
  tools/ItemMappingBuilder/    # 双语映射表生成工具
  index.html                   # 前端入口
  app.js                       # 前端逻辑
  search-ranking.js            # 本地模糊搜索排序
  styles.css                   # 前端样式
```
