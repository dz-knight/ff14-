# FF14 物价百科 v1.0.3

面向《最终幻想 XIV》国服玩家的桌面查价工具。

当前核心查询链路：
`中文搜索 -> 内置双语映射表 -> ItemID / 英文名 -> Universalis 国服价格`

## 主要功能

- 国服市场板价格查询
- 物品详情、配方、用途、获取方式查看
- 国服 Wiki 词条直达
- 中文 / 英文双语物品映射
- `全部 / HQ / 非 HQ` 价格查看
- 白天 / 黑夜主题切换

## 启动方式

源码运行：

```bat
start_app.bat
```

发布打包：

```bat
publish_app.bat
```
