FF14 物价百科桌面版 v1.0.9 使用说明

一、启动方式
直接双击：
FF14MarketDesktop.exe

二、本次版本重点
1. 中文模糊搜索
- 输入“秘银”会快速显示“秘银矿”等本地候选
- 模糊搜索和同名条目不会自动跳转，请从候选中选择准确物品
- 候选会显示物品或任务 ID，便于区分同名条目

2. 查询容错
- 物品与任务分别查询，某一类远程数据失败时不影响另一类候选
- CafeMaker 暂时不可用时，本地物品搜索和 Universalis 市场价格仍可继续使用

三、支持内容
- 国服市场板价格查询
- 当前区服销售排行
- 配方成本与利润计算
- 物品详情与百科查看
- 任务详情
- 国服 Wiki 联动浏览

四、搜索说明
1. 搜索物品
- 直接输入中文物品名即可
- 例如：秘银矿、玄铁矿、高山茶

2. 搜索任务
- 推荐使用任务 ID
- 例如：
  任务:66358
  quest:66358
  q:66358

五、注意事项
- 请保留整个发布文件夹，不要只单独复制 exe
- 首次启动时加载双语映射与区服数据会稍慢，属于正常现象

六、版本
- 当前版本：v1.0.9
