FF14 物价百科桌面版 v1.0.6 使用说明

一、启动方式
直接双击：
FF14MarketDesktop.exe

二、本次版本重点
1. 当前区服销售排行
- 支持中国全区、大区、世界服范围
- 支持价格排行和销量排行，默认展示前 30 名

2. 配方成本与利润计算
- 点击“计算利润”后再加载材料价格
- 显示材料单价、成本总价、当前售卖最低价、税后利润和利润率

3. 速度和显示修复
- 优化销售排行加载速度
- 修复网页排行物品名和图标显示问题

三、支持内容
- 国服市场板价格查询
- 当前区服销售排行
- 配方成本与利润计算
- 物品详情与百科查看
- 任务详情
- 国服 Wiki 联动浏览

四、搜索说明
1. 搜索物品
- 直接输入中文物品名即可
- 例如：秘银矿、玄铁矿、高山茶

2. 搜索任务
- 推荐使用任务 ID
- 例如：
  任务:66358
  quest:66358
  q:66358

五、注意事项
- 请保留整个发布文件夹，不要只单独复制 exe
- 首次启动时加载双语映射与区服数据会稍慢，属于正常现象

六、版本
- 当前版本：v1.0.6
