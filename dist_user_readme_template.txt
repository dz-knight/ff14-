FF14 物价百科桌面版 v1.0.3 使用说明

一、启动方式
直接双击：
FF14MarketDesktop.exe

二、本次版本重点
1. 国服 Wiki 词条直达
- 物品详情中的国服 Wiki 按钮现在优先直达对应详细页

2. 主题切换
- 新增白天 / 黑夜主题切换
- 软件会记住你上次选择的主题

3. 市场价格修复
- 修复 `HQ / 非 HQ` 模式下世界服价格表排序异常
- 修复部分页面中的乱码文案

三、支持内容
- 国服市场板价格查询
- 物品详情与百科查看
- 任务详情
- 国服 Wiki 联动浏览

四、搜索说明
1. 搜索物品
- 直接输入中文物品名即可
- 例如：秘银矿、玄铁矿、高山茶

2. 搜索任务
- 推荐使用任务 ID
- 例如：
  任务:66358
  quest:66358
  q:66358

五、注意事项
- 请保留整个发布文件夹，不要只单独复制 exe
- 首次启动时加载双语映射与区服数据会稍慢，属于正常现象

六、版本
- 当前版本：v1.0.3
