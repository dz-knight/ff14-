FF14 物价百科桌面版 v1.1.3 使用说明

一、启动方式
直接双击：
FF14MarketDesktop.exe

二、本次版本重点
1. HQ / 非 HQ 品质筛选修复
- 搜索并打开商品后，在“市场总览”顶部选择“品质：全部 / HQ / 非 HQ”
- 本地映射或百科资料缺失不会再隐藏品质筛选，不限于高山茶
- 最低价、上架数和库存量按所选品质统计；没有该品质的上架时显示“暂无上架”
- 品质资料未知时保留筛选不代表该物品一定能制作 HQ

2. 国服招募查询
- 点击首页“查招募”查看当前国服招募
- 支持名称或描述搜索、大区和任务分类筛选、分页、刷新与详情
- 特殊迷宫没有活跃招募时会显示空结果，属于实时数据的正常状态

3. 查询容错
- 快速连续切换条件时只保留最新结果
- 部分分页失败时会显示提示，不会把残缺数据伪装成完整结果
- 物品与任务仍分别容错，CafeMaker 不可用时本地搜索和 Universalis 市场价格可继续使用

三、支持内容
- 国服市场板价格查询
- 当前区服销售排行
- 配方成本与利润计算
- 物品详情与百科查看
- 任务详情
- 国服实时招募查询
- 国服 Wiki 联动浏览

四、搜索说明
1. 搜索物品
- 直接输入中文物品名即可
- 例如：秘银矿、玄铁矿、高山茶

2. 搜索任务
- 推荐使用任务 ID
- 例如：
  任务:66358
  quest:66358
  q:66358

五、注意事项
- 请保留整个发布文件夹，不要只单独复制 exe
- 首次启动时加载双语映射与区服数据会稍慢，属于正常现象

六、版本
- 当前版本：v1.1.3
