FF14 物价百科桌面版 v1.0.4 使用说明

一、启动方式
直接双击：
FF14MarketDesktop.exe

二、本次版本重点
1. 主题调色
- 支持颜色盘直接选色
- 支持输入 `RGB` 颜色代码手动调色

2. 透明度调节
- 桌面端窗口支持 `10%` 到 `100%` 自由调节

3. 代码清理
- 清理重复前端逻辑，减少旧代码覆盖新逻辑的风险
- 搜索链路保持不变

三、支持内容
- 国服市场板价格查询
- 物品详情与百科查看
- 任务详情
- 国服 Wiki 联动浏览

四、搜索说明
1. 搜索物品
- 直接输入中文物品名即可
- 例如：秘银矿、玄铁矿、高山茶

2. 搜索任务
- 推荐使用任务 ID
- 例如：
  任务:66358
  quest:66358
  q:66358

五、注意事项
- 请保留整个发布文件夹，不要只单独复制 exe
- 首次启动时加载双语映射与区服数据会稍慢，属于正常现象

六、版本
- 当前版本：v1.0.4
